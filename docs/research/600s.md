# 600S research package

The canonical 600S evidence package now lives in [`600s/`](600s/):

- [`REFERENCES.md`](600s/REFERENCES.md) - source identity, applicability, purpose, and confidence
- [`DIMENSIONS.md`](600s/DIMENSIONS.md) - published, derived, and visual-approximation boundaries
- [`ARTICULATION.md`](600s/ARTICULATION.md) - verified motions and unresolved kinematic limits
- [`reference-board/README.md`](600s/reference-board/README.md) - the 12-view modeling board manifest

Do not add a numeric value to the production viewer unless it is classified in `DIMENSIONS.md` or `ARTICULATION.md`.
