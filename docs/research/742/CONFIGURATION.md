# Frozen configuration

`742-PVC2411-US-STD-OC-D36-FF370-C50-PF481`

- Model/PVC: 742 / 2411
- Market/serial family: ANSI US / 0160116278 and after
- Engine: standard Deutz TCD 3.6L L4, 72 hp
- Drive: 4x4 powershift
- Steering: selectable four-wheel circle, four-wheel crab, two-wheel front
- Tires: standard 370/75-28
- Operator station: standard open cab
- Attachment: 50 in (1.27 m) standard fully floating carriage
- Forks: first listed pallet fork, 2.36 x 4 x 48 in; modeled as 60 x 102 x 1219.2 mm because 48 in is exact and the listed 1200 mm is rounded
- Options: none

The specification calls the 72 hp engine standard, while the parts manual labels branches `74HP` and `110HP`. The reconstruction follows the consumer-facing 72 hp standard identity and uses the parts branch only as topology evidence; it does not infer a power conversion or engine tune.

The standard/open-cab choice is supported by the options list (`Enclosed Cab` is optional), the current gallery, and the PVC 2411 open-cab parts group. The exact fork choice is a deliberate freeze from the first pallet-fork size in the current specification, not a claim that every photographed unit uses that fork.
