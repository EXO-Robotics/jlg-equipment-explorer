# JLG 742 evidence freeze

This packet supports the owned 742 Equipment Explorer reconstruction at configuration `742-PVC2411-US-STD-OC-D36-FF370-C50-PF481`.

The admission order is current JLG specification and brochure, the complete PVC 2411 publication family, official current gallery views, and then JLG BIM files as temporary visual/envelope references. Manufacturer PDFs, gallery binaries, BIM files, and extracted geometry are never shipped. The repository contains only hashes, citations, independent measurements, written findings, and the owned reconstruction.

The model freezes the standard 72 hp Deutz configuration, open cab, standard 370/75-28 tires, 50 in floating carriage, and the first listed 48 in pallet-fork choice. Any option not named by that configuration is excluded.

All moving coordinates are display reconstruction unless a claim explicitly says `published-dimension` or `evidence-derived stroke`. The maximum-height pose reconciles the level fork surface to 12.7989 m against the published 12.8 m, and a distinct low-angle reach pose reconciles the 24 in load center to 8.8700 m against the published 8.86 m. The selected blades use the exact 48 in length (1.2192 m) and the published 60 x 102 mm cross-section orientation. Evidence-derived cylinder strokes, the 55-degree steering limit, and documented topology constrain the display, but reconstructed anchors, steering curve, flexible routing, and linkage coordinates remain non-authoritative. No load chart, dynamics, stability behavior, interlock, safe operating procedure, hydraulic response, service geometry, or safety behavior is simulated.
