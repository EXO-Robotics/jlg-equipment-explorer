# Reference board policy

The reference board is intentionally text-only in the repository. Temporary local boards may contain official gallery and rendered PDF images, but they must remain outside deployable paths.

Required angles: stowed right side, extended front-left, extended front-right, cab close-up, boom-head/carriage, undercarriage/axles, and maximum-reach side silhouette. Compare the owned render against each view without tracing or importing manufacturer geometry.
