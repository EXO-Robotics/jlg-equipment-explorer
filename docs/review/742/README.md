# 742 local review evidence

`review-manifest.json` binds these local human/product observations to one exact
candidate tree and reviewed source commit. The binding is intentionally updated
only after the candidate is committed and the observations are repeated.

The PNGs are deterministic renders from the independently authored Blender
source and are admitted by `OWNED_RENDER_ALLOWLIST.json` using exact paths,
hashes, byte counts, and image dimensions. The extended visual gate binds five
separate maximum-lift, maximum-reach, retract-chain-cutaway, and
steering-cutaway views instead of asking one distant frame to prove every
mechanism. Separate gate-specific JSON records
capture desktop, portrait, short-landscape, keyboard-modal, semantic-selection,
frame-time, exact-upstream 600S, and exact-upstream ES1930M browser checks. They
expressly do not claim physical screen-reader, low-end mobile GPU,
deployment, operational, load, stability, service, or safety proof.
